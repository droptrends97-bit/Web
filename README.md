# darraghconnolly.ie

The redesigned site for Darragh Connolly Garden Care, built with Astro as a static site.

```
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```

Deploy the `dist/` folder to Netlify. The quote form uses Netlify Forms.

- Content (services, months, testimonials, gallery) lives in `src/data/site.ts`.
- Product facts are recorded in `PRODUCT.md`, and the visual system in `DESIGN.md`.
- Photos in `public/img/` are crops from screenshots of the old site. Replace them with full-resolution originals.
