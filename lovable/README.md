# coastal-web-craft (Lovable) — homepage source

Working copy of the two files that make up the East Coast Digital homepage in
the Lovable project `460532af-149e-4f0b-830e-6ad2bddbb10c`. Lovable has no git
connection, so these are kept here as the editable source of truth and copied
into the project verbatim.

- `src/routes/index.tsx` — the homepage
- `src/styles.css` — Tailwind v4 theme plus the page's own CSS

Both are typechecked against the project's imports before shipping.
